# AWJ · أوج — منصة ذكاء السمعة الرقمية

موقع متعدد الصفحات (Multi-Page HTML) ثلاثي اللغة (عربي RTL · فرنسي · إنجليزي).
لا إطار عمل، لا SPA — كل صفحة ملف HTML مستقل، جاهز للنشر على Netlify.

## الصفحات
- `index.html` — الواجهة (الرادار، الطبقات الأربع، الوكلاء)
- `platform.html` — تفصيل المنصة وكيف تعمل
- `pricing.html` — الباقات: أفراد · شركات · كيانات سياسية
- `dashboard.html` — العرض الحي التفاعلي (غرفة العمليات)
- `trust.html` — ميثاق الأخلاقيات (ما نفعله / ما لا نفعله)
- `contact.html` — نموذج طلب تحليل مجاني

## الأصول
- `assets/css/awj.css` — التصميم (ثيم داكن، ذهبي + سماوي، RTL-aware)
- `assets/js/awj.js` — الترجمة (124 مفتاحاً × 3 لغات) + التفاعلات
- `assets/img/awj-mark.svg` — اللوجو

## اللغة
زر اللغة في الشريط العلوي (ع / FR / EN). الاختيار يُحفظ محلياً،
واتجاه الصفحة يتبدّل تلقائياً بين RTL و LTR.

## النشر على Netlify (نفس مسار WEBIQ)
1. ادفع المجلد إلى مستودع GitHub جديد (مثلاً `Ahas2020/awj-site`).
2. في Netlify: New site → Import from GitHub → اختر المستودع.
3. Build command: (فارغ) — Publish directory: `.`
4. اربط النطاق (مثلاً `awj.ai` أو `theawj.pro`) بعد التحقق من توفّره.

## ملاحظة عن العرض الحي
لوحة `dashboard.html` تعمل الآن ببيانات نموذجية (JS محلي) لتعرض التجربة
على أي استضافة. الربط الحقيقي بالمصادر والذكاء الاصطناعي يحتاج خلفية
(Backend) — راجع مخطط المعمار في رسالة الشراكة.
